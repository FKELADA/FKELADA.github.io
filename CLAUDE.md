# fkelada.github.io

Fadi's public personal site (Astro, static, GitHub Pages). English at the root, French under `/fr/`. See `README.md` for commands and where content comes from.

## Rules

- **This repo is public and deployed on every push to `main`.** Only publish what Fadi asked for.
- `src/data/*.json` and `src/assets/portrait.jpg` are generated by `node hub/cli.mjs sync-site` (run from Fadi-Global). Change the sources (`cv/cv.yaml`, `projects.yaml`) instead, then sync.
- Never add the phone number, street address, referee contacts, anything from FidoFinance, or Khedma data. The sync already filters these: keep it that way.
- Every page exists in both languages. Views in `src/views/` take `lang`, and `src/pages/` and `src/pages/fr/` are thin wrappers around them. Interface strings go in `src/i18n.ts`, for both languages.
- Before committing: `npm run build` (runs `astro check`).
